## Performance

* **Parked locomotives still deform rods.** In `DriveRetarget.LateUpdate` (lines 321–392), fixed-endpoint and anchored meshes rewrite vertices, normals and bounds, and tangents when UVs are present. There is no unchanged-pose check. The hidden-linkage work in the preceding 2.0.9.4 commit extends this path to multiple arrangements and LODs. An unchanged relative transform is a useful case to measure alongside a moving engine. Preserve animated oil-point updates.
* **Articulated physics creates garbage on each force application.** `IndependentDrive.ApplyForce` allocates the contact matrix and transmitted-force vector each time. `GroupForceRouting.Distribute` allocates another vector. Contact assignments are fixed for that drive binding. `NativeSlipRuntimeState.Prepare/Bridge/Sample` also call world-wide `CompleteAllJobs` for each ready owner, and `GroupSlipEffects.Tick` scans the full car hierarchy ten times per game-time second for each active owner. The code establishes recurring work. Its frame-time and GC impact with several active cars remains unmeasured.
* **First use and switching have distinct costs.** Mesh extraction waits synchronously, with a 60-second timeout per process. Franklin wheel OBJ files are cached on disk, but a multi-engine bind still repeatedly reads and measures the same wheels across drive sides. Preserve the existing native pin/constraint solution when addressing object lifetime or measuring switching latency.
