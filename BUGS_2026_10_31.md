## Confirmed causes and changes

### ECS registration after game startup

The installed Unity.Entities TypeManager knows component types discovered when
it initializes. The old native fixture loaded the probe/mod assembly before
that boundary. A real game already has an initialized ECS registry when UMM
loads the mod; the custom Ownership tag is therefore unknown.

An isolated Unity 2019.4.40f1 release player now loads the native game/transform
assemblies and initializes TypeManager before loading the frozen old probe.
That reproduces the exact reported unknown Ownership exception at
NativeSlipEntitySchema.AdhesionCarrier. The constructor propagates the failure
to the arrangement converter, which restores stock, explaining the rollback.

The fix removes the unnecessary custom ECS component. Both archetypes use only
existing native game components. Runtime ownership remains in private conversion
wrappers and the runtime object's disposed state; native versioned Entity
identities reject writes to retired entities. No global registry reset, private
type-registration hook, package update or replacement physics system is added.

### Connect-once API used for replacement

The installed DV.Simulation PortReference.SetPortReference logs an error and
refuses an already-connected input. IndependentDrive incorrectly called it
both when acquiring the independent RPM input and when restoring the original.
Cleanup before the first sample could therefore produce the reported duplicate
connection warning even though activation itself had already failed.

The fix leases the existing engine's crankRpm.port directly, as the retained
tender engine already does for its synchronous native RPM adapter. The original
reference is restored only while this activation still owns the input. Guests
continue to leave RPM references untouched. A replacement owner's input is not
overwritten by a retiring old owner.

The old test boundary incorrectly allowed SetPortReference to reconnect.
It now matches the native refusal semantics. Running the frozen old production
source fails the RPM activation assertion; current production passes, including
pre-activation cleanup, repeated release and replacement-owner protection.
