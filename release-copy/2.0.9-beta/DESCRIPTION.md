# Rearranged S282 2.0.9-beta

This optional multiplayer beta uses the full **2.0.8-slip-test** base, including experimental independent locomotive-group wheelslip and its latest fixes. Choose from **49 S282 arrangements**, including the Express Mountain, Mallets, locomotive triplexes and Erie powered tender. There are **44 compatible powered-tender choices**.

Everyone can use their own Wheel Rearranger radio. The host validates changes and shares the layout and its relevant preferences. Under **Ctrl+F10 > Rearranged S282**, the host can allow all guests or block individual players from changing arrangements. Blocked players still see updates. Permissions reset when that player leaves.

Install through UMM with Derail Valley B99 and Locomotive Mesh Splitter. For multiplayer, everyone needs **DV Multiplayer 0.1.16.0-beta** and this exact complete package. Remove the previous RearrangedS282 folder before installing; use one build at a time. Multiplayer is optional for single-player use. Please leave Realistic Firing off.

The host owns traction calculations. Guests use native replicated ports for independent-group RPM, slip and phase; the native multiplayer mod handles train movement. The powered tender still uses the earlier pooled/manual traction and locomotive-linked RPM. Independent tender slip and true compound expansion are not implemented.

This is an experimental beta awaiting live multi-PC testing. Local code and native calculation checks cannot establish live driving, audio, visuals or save behavior. Have fun, try the radios and host locks, and let me know if something breaks. The layout and Player.log from the host and affected guest are useful.

The plain README, detailed optional testing notes, credits and licences are included in the ZIP. Original mod by SatiricRug / Peter Schinske; B99 continuation by JimTaplin.
