REARRANGED S282 B99 - 1.21.2 BETA

B99 continuation of SatiricRug's Rearranged S282 by JimTaplin.
47 selectable arrangements including conventional layouts articulated Mallets
and experimental triplexes. This update adds no new wheel arrangements.

REQUIREMENTS
Windows, Derail Valley B99, Unity Mod Manager 0.27.3 or later and Locomotive
Mesh Splitter (1.1.9 tested). Retain all included assets and exporter files.
MultiCylinderChuffFix in LoadAfter is an optional load-order hint, not a required
mod. Other optional load-order entries are not hard requirements either.

INSTALL AND USE
Close the game and install the ZIP through UMM as an update to RearrangedS282.
Open Wheel Rearranger on the comms radio. Stop and close the regulator before
changing arrangements. Selections are remembered per locomotive.
Existing settings are retained when updating; defaults may differ from your
saved options. See UMM_OPTIONS.md for descriptions and reapply instructions.

WHAT CHANGED
See CHANGELOG.txt for changes since public 1.13.6. Driver spacing and rod reach,
steam pipes/manifolds, rear Mallet driver rotation, calculated grip/cylinder
balance and diagnostics have been updated. Stock S282 physics remains unchanged.
The 2-2-2 remains an unfinished non-colliding clearance prototype.

BETA STATUS
The 1.20 build passed all 47 live structural checks and representative power
captures. Its visible running gear and pipe appearance were accepted in testing.
The later 1.21.2 balancing pass passes the existing native-engine and compiled
checks but has not yet received an in-game acceptance run. This package uses
exactly the installed 1.21.2 runtime DLL, with cleaned release documentation.
Do not interpret the calculated TE table as guaranteed career tonnage or speed.

KNOWN LIMITS
A public report of a missing front valve-gear crank on an unspecified duplex is
still under investigation. An independently selectable powered tender for other
locomotive layouts is not implemented. Erie tender traction/presentation remains
experimental. Realistic Firing compatibility, multiplayer and VR are unverified.
Temporary precision tuning sliders remain in this beta and are not necessary
for normal play. They are not promised as permanent release controls.
