# Rearranged S282 2.0.9-beta.1 options

Open **Ctrl+F10 > Rearranged S282**. Host session permissions allow all guests or block specific players from changing arrangements. Blocked guests still receive updates. Permissions reset when the player leaves. Only the host edits shared arrangement preferences during an online session.

Stop, close the regulator and highlight the S282 with Wheel Rearranger. **REAPPLY CURRENT ARRANGEMENT** applies changed appearance/tender preferences to that locomotive. **RESET WHEEL-ARRANGER RADIO SELECTION** clears the local radio selection. Each player's radio operates independently.

Powered-tender options cover **44 compatible layouts**, with Erie enabled by default. A regular S282 tender must be coupled behind the locomotive. The three-engine locomotive triplexes, unpowered 4-0-4 and unfinished giant 2-2-2 are excluded. Untick Erie and reapply to use an ordinary tender.

Valve-gear, trailing-truck, curve drag/squeal, big-end oilcup and automatic oiling choices retain the selected base's behavior. Reapply appearance changes. Automatic oiling is off by default. Native oiling state is written by the host during multiplayer.

Random spawning is off by default. Select the desired layouts for its pool; saved choices remain with their locomotives and an empty pool falls back to stock. The host chooses online spawns; guests wait for the accepted layout.

The selected locomotive shows independent-drive status. **RECORD GROUP SLIP DIAGNOSTICS** writes independent-slip.jsonl locally at four samples per second. Stop recording after reproducing a problem. The artificial grip test and structural tests are available only outside multiplayer sessions.

Without an active online session, ordinary single-player preferences and controls apply. Multiplayer permissions/status stay hidden. Diagnostic fixtures do not establish live visual or driving acceptance.
