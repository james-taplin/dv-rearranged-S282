REARRANGED S282 - B99
Version 1.13.6 Beta | JimTaplin
Based on Rearranged S282 by SatiricRug (Peter Schinske)

47 selectable arrangements, including conventional conversions, articulated
Mallets and triplexes, the unpowered 4-0-4 and an experimental giant-driver 2-2-2.

REQUIREMENTS
Windows, Derail Valley B99, Unity Mod Manager 0.27.3 or later, and Locomotive
Mesh Splitter (1.1.9 tested): https://www.nexusmods.com/derailvalley/mods/867
Optional Model Tweaks / DV Car Changer integration supplies Delta truck styling;
those mods remain separate installations. They are not required to use this mod.

INSTALLATION AND UPDATES
Close the game. Back up your save and existing Settings.xml before upgrading.
Install this ZIP with Unity Mod Manager, updating the existing RearrangedS282
entry. Do not install the original mod alongside this fork. Manual installation:
copy the included RearrangedS282 folder into the game's Mods directory, replacing
release files and retaining your existing Settings.xml. The resulting path is
Mods/RearrangedS282/Info.json. Keep the exporter, assets and licences folders.
Restart the game after updating; hot reload is not supported.

USE AND SETTINGS
Use Wheel Rearranger on the comms radio, point at an S282 and confirm a layout.
Stop and close the regulator before switching. Choose 2-8-2 Mikado for stock.
Choices are saved per locomotive. The first conversion may briefly prepare rod
meshes. Ctrl+F10 opens UMM settings and the optional diagnostic/test controls.
Random spawning is off by default and its pool can be configured. Experimental,
high-speed and articulated choices are excluded from the default pool.

INCLUDED FEATURES
- 47 arrangements with native B99 radius/RPM and powered-axle registration.
- Articulated front engine groups using DV bogies and constraints.
- Auxiliary native steam engines with boiler demand and exhaust accounting.
- Optional random spawning, saved selections, trailing-truck and valve-gear options.
- Optional curve drag and squeal accounting for rigid groups, blind drivers and
  approximated lateral play. Extra derailment stress is not implemented.
- Big-end oil cups, native oil controls, explosion materials and Delta compatibility.
- Current Prairie placement, selected casing normalization, resized high-speed
  drivers and 4-14-4 spacing. See CHANGELOG.txt for recent changes.

BETA LIMITATIONS AND COMPATIBILITY
Realistic Firing compatibility is unsupported in this beta, especially its
cylinder-model feature. Compatibility with future versions is not ruled out.
Multiplayer synchronization and VR have not been validated.
The giant-driver 2-2-2 is a clearance prototype with its rods hidden.
The Erie powered tender is experimental: its separate traction clamp is a
simplification and tender chuff/exhaust/smoke, cocks, slip presentation, brake heat
and LOD work remain unfinished. Other engine groups share native locomotive slip.
These conversions are not historical compound-engine or performance calibrations.
The proposed cylinder-power and adhesive-weight rebalance is not included.
The 1.13.5 structural test passed all 47 layouts; latest Prairie placement awaits
recorded game acceptance. See TEST_STATUS.txt and MANUAL_TEST_CHECKLIST.txt.
