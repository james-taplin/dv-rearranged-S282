SHORT DESCRIPTION
47 S282 wheel arrangements for B99 with articulated Mallets and triplexes saved
choices oil cups and optional curve drag and squeal

DESCRIPTION
B99 continuation of SatiricRug's Rearranged S282 with 47 selectable arrangements.
Includes conventional and articulated layouts, native auxiliary steam engines,
optional random spawning, saved per-loco selections, oil cups, cylinder and rod
polish, and optional curve drag and squeal.

This update moves the Prairie cylinders running gear and drivers rearward together
while retaining the smaller reservoir-clear wheels and current rod geometry.

Requires Windows, Derail Valley B99, Unity Mod Manager 0.27.3 or later and
Locomotive Mesh Splitter (1.1.9 tested):
https://www.nexusmods.com/derailvalley/mods/867

Close the game before updating and back up saves and Settings.xml. Install using
UMM over the previous RearrangedS282 version. Keep included assets and exporter.
Select layouts with Wheel Rearranger on the comms radio while stopped with the
regulator closed. Random spawning is optional and off by default.

BETA STATUS
All 47 layouts passed the structural test on 1.13.5. The latest 1.13.6 Prairie
position passes offline checks; final in-game visual/driving acceptance remains
pending. Realistic Firing is unsupported for this beta. Multiplayer and VR are
unverified. The giant 2-2-2 and Erie tender engine remain experimental; see README.
